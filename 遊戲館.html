02 / QUICK START

六步驟快速掌握遊戲操作

這是依目前公開入口設計的建議使用流程。遊戲選單、開始方式與控制鍵請以實際遊戲畫面提示為準。

01

開啟遊戲館

按下「開啟 CodeByX 遊戲館」或使用手機掃描本頁 QR Code，進入原網站。

02

認識首頁

先確認網站名稱與操作入口，留意右上方的「音效開啟」及「我的紀錄」。

03

選擇遊戲

在原站實際顯示的遊戲清單中挑選一款，閱讀它的遊戲規則和控制提示。

04

開始挑戰

依所選遊戲的開始按鈕或操作指示進行，注意計時、分數及結束條件等站內規則。

05

查看我的紀錄

完成遊戲後回到入口，按「我的紀錄」查看目前能查閱的遊玩資料。

06

調整音效與再挑戰

依環境需要開關音效，再依畫面選擇重新開始、返回遊戲列表或挑戰其他遊戲。

小提醒：若是在課堂或公開場合使用，建議先確認裝置音量。若在不同瀏覽器或手機開啟，不要預期紀錄會自動同步。

05 / QUESTIONS

常見問題

依原站公開內容與一般瀏覽器使用原則整理。

Q1｜需要註冊帳號或輸入 OpenAI API Key 嗎？

原站明確標示「無需 API Key」，但公開內容未提供完整帳號機制說明。請以實際網站操作提示為準。

Q2｜換手機後，我的遊戲紀錄會同步嗎？

原站標示紀錄儲存在目前瀏覽器，不能據此推論有跨裝置同步。重要紀錄建議先截圖保存。

Q3｜沒有聲音怎麼辦？

先查看原站音效按鈕狀態，再檢查裝置音量及瀏覽器分頁是否靜音。瀏覽器可能限制互動前自動播放。

Q4｜有哪些小遊戲？有幾款？

原站的公開可讀文字沒有完整列出遊戲品項，請點擊進入網站，以實際顯示的遊戲清單為準。

Q5｜這份介紹頁與 QR Code 可以離線使用嗎？

可以。這份 HTML 的文字、插畫、樣式及 QR Code 均內嵌，離線仍可開啟介紹頁；但連往原網站需要網路。

Q6｜適合拿來做招生或教學展示嗎？

適合。可透過介紹頁說明互動網站概念、展示遊戲入口與 QR Code，並請學員比較遊戲的操作體驗。實際遊戲功能以原站為準。

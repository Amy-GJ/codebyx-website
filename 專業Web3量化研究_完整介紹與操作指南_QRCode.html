02 / QUICK START

六步驟快速上手

以可確認的網站入口為基礎，規劃保守、實用的新手操作順序。

01

點擊本頁的「開啟 CodeByX Quant Lab」按鈕，或用手機掃描 QR Code 進入原站。

02

先查看「CodeByX Quant v1.0 / 研究版」、本機資料提醒，以及無實盤下單聲明。

03

06 / QUESTIONS

常見問題與風險說明

Q1｜這是交易機器人嗎？能直接買賣嗎？

原站定位為現貨研究工作站，並明確寫出無實盤下單。不能把它視為已經具備下單或自動交易服務。

Q2｜需要提供 API Key 或私鑰嗎？

原站明示「無交易密鑰 · 無 AI API Key」。請勿將交易密鑰、錢包私鑰或助記詞貼入未確認的欄位。

Q3｜行情是即時的嗎？有哪些資料來源？

公開畫面僅可看到「連線中」提示，不能據此證實行情來源或刷新頻率。應以原站相關模組中的來源與時間資訊確認。

Q4｜支援 BTC、ETH、SOL 以及其他標的嗎？

公開可讀首頁尚無完整標的清單。進入原站後查看選單與標的選擇器；本介紹頁不假定已支援哪些幣種。

Q5｜會自動備份或跨裝置同步嗎？

原站說明研究留在本機，且有匯出備份按鈕，但未核實自動備份或跨裝置同步。請定期自行匯出並妥善保存。

Q6｜介紹頁的深淺色切換會修改原站嗎？

不會。深色與淺色模式只作用於這份介紹 HTML，不代表原始 Quant Lab 已內建相同的主題切換。

Q7｜可以拿來進行投資課程展示嗎？

可以作為研究工具導覽與資料品質、風險控管的教學示範。應強調非投資建議、非即時報價保證，且不應承諾投資成果。
